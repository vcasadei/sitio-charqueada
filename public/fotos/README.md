## Dicas

- **Formato:** `.jpg` recomendado (mais leve). `.png` também funciona — basta
  mudar a extensão em `src/data/media.ts`.
- **Tamanho ideal:** 1600–2400px no lado maior, qualidade 80%.
  Use [squoosh.app](https://squoosh.app) para comprimir.
- **Orientação:** o site mistura aspectos (portrait/landscape) automaticamente.
